| Git Command | Function |
|---|---|
| `git init` | Initializes a Git repository. |
| `git add .` | Adds all project files to staging. |
| `git status` | Checks modified and untracked files. |
| `git commit -m "message"` | Saves changes to the repository. |
| `git branch` | Displays project branches. |
| `git push` | Uploads committed changes to GitHub. |
| `git pull` | Downloads the latest changes from GitHub. |
| `git clone` | Copies a repository from GitHub. |
| `git log` | Displays commit history. |
| `git remote -v` | Displays connected remote repositories. |
